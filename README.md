# Lab Assets Repository

This is the lab assets library for public labs managed by Google Cloud Learning Services (CLS) and contains code files, notebooks, etc, that are provided in public labs on skills.google.

This repository does not seek public contributors. Issues or pull requests submitted by the general public are not actively monitored or reviewed. 


## Repository Layout

```
lab-assets/
├── labs/
│   └── gspXXXX/                  # Subdirectories created for public labs (identified by the GSP number)
└── README.md                     # Repository documentation (this file)
```
